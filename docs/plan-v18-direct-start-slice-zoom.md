# 計畫 v18：開啟直接進主畫面、切面可以放大

> 位置：`docs/plan-v18-direct-start-slice-zoom.md`，分支 `simple-version`（接在 `4c46d8f` v17 M17.6 之後）。
> 出發點：2026-11-11 使用者對簡化版提的兩點（§1）。
> 範圍：只動畫面層（`index.tsx`、一個新元件、`styles.css`、e2e 腳本、README）。**核心規則、Worker、匯出、復原堆疊都不動。**
> 取代 v17 的兩句話：§5.1「拿掉…切面右上角的『進入 2D 剖面』」、§5.7「沒有…放大成主畫面」。放大回來了，但仍然**唯讀**（R3 不變）。
> 狀態：只有計畫，還沒實作。

---

## 0. 一句話

打開網頁就是主畫面（自動載入簡單範例，上傳改成只從頂端列的按鈕進）；每張切面右上角多一顆放大鈕，放大後它變成主畫面、可以用滾輪縮放與拖拉平移，做法照 `claude/upbeat-einstein-wod16i`，但拿掉所有編輯。

## 1. 需求

| # | 使用者說的 | 這份計畫怎麼解讀 | 章節 |
|---|---|---|---|
| R1 | 這個版本一開始不需要有上傳的畫面，直接到主畫面就好 | 拿掉歡迎頁；開啟時自動載入**簡單範例**。上傳功能保留在頂端列的「上傳 .vti」對話框 | 3.1 |
| R2 | 2D 圖跟 `claude/upbeat-einstein-wod16i` 版本一樣要可以放大 | 兩件事一起回來：(a) 切面放大成主畫面、3D 與另外兩張縮成小窗；(b) 主切面上滾輪縮放、拖拉平移、右下角縮放列 | 3.2 |

## 2. 查證：現況

**R1**
- 歡迎頁在 `src/pages/Section3D/index.tsx:452-470`：`!ed.ready` 時整頁換成標題＋`UploadPanel`。
- `ed.ready` ＝有沒有載入過（`editor.ts:160`）。範例由 `ed.demo('basic' | 'complex')` 載入（`editor.ts:592`），內部走 `loadVolume`，已有 `running` 旗標擋重複呼叫（`editor.ts:553`）。
- 上傳對話框（`index.tsx:504-506`）和歡迎頁用同一個 `UploadPanel`，裡面已經有兩顆範例按鈕，所以拿掉歡迎頁不會少功能。
- 三支 e2e 都是「歡迎頁 → 點『簡單範例』」開始：`scripts/e2e/m0.cjs:21`、`m17.cjs:24`、`perf.cjs:19-28`。
- `views.lazy.tsx` 把 three.js 延後到「載入檔案後」才抓；之後一開啟就需要。
- `main.tsx` 有 `StrictMode`：開發模式 effect 會跑兩次。

**R2**
- 現在三張切面都是 `SliceView`（`views.tsx:1574`）：圖永遠塞滿格子（`ResizeObserver` 算等比尺寸），滾輪＝換片，點＝選取。沒有縮放、沒有放大鈕。
- 完整版的做法（`git show origin/claude/upbeat-einstein-wod16i:<檔案>`）：
  - **放大成主畫面**：`index.tsx` 的 `slice()`／`mainSlice()`，`.canvas-area` 加 `editing focus-{axis}` class，版面全靠 CSS grid 重排（`styles.css:167-188`），DOM 不搬，所以 WebGL 不重建。
  - **縮放與平移**：`SliceEditor.tsx` 的 `ViewXf { zoom, tx, ty }`（`:84-94`）、`fit`／`aim`／`zoomAt`（`:365-390`）、每個方向記住上次的縮放（`:393-412`）、滾輪（`:414-432`）、空白鍵平移（`:433-454`）、視窗改大小保持中心（`:455-465`）、平移的 pointer 處理（`:886-935`）、縮放列（`:1092-1115`）；樣式是 `.sedit*`（`styles.css:197-205`）。
  - 完整版的放大＝進入 2D 編輯（要先選結構才能按、有節點／把手／浮動工具列）。這些 v17 已經刪掉，**不搬回來**。

## 3. 設計

### 3.1 開啟直接進主畫面（R1）

- **自動載入**：`Section3DPage` 掛上時 `ed.demo('basic')` 一次。`StrictMode` 的第二次呼叫被 `loadVolume` 的 `running` 旗標擋掉，不必另外處理。
- **載入中的畫面**：頂端列照常（品牌＋「上傳 .vti」可按、「匯出」反灰），下面整塊置中一行「載入範例中…」。簡單範例很小，這個畫面只會閃一下；不做骨架屏。
- **載入失敗**（理論上不會，Worker 起不來才會）：同一塊改顯示錯誤訊息＋「重試」＋「上傳 .vti」，不留白畫面。
- **上傳對話框提到最外層**：現在 `Modal` 只在 `ed.ready` 的分支裡；改成單一個 return，`ed.ready` 只決定 `.body` 裡放主畫面還是上面那一行，這樣載入中／失敗時也開得了上傳。
- **頂端列的字**：沿用 `{ed.meta.name}`，會顯示「簡單範例 · 160×96×128…」。
- **「上傳 .vti」對話框不動**：仍可上傳 `.vti`／`.npy`，也仍有「簡單範例」「複雜範例」兩顆按鈕（換回範例、或看複雜範例的入口）。
- **提早抓 3D 引擎**：`index.tsx` 模組載入時就 `void import('./views')`，和範例的結構分析同時進行；`lazy` 的分塊照舊（three.js 不進首包）。
- **刪掉**：歡迎頁的 JSX、`.welcome*` 三條樣式（`styles.css:187-189`）。

### 3.2 切面放大（R2）

**放大成主畫面**

```
一般（不變）                              放大 XY 正面（寬 ≥ 1200 px）
┌───────────────────────────┐           ┌──────────────────────┬────────┐
│ 3D                        │           │ [← 回 3D] [XY|XZ|YZ]  │ 3D   ⤢ │
│                           │           │ ‹ z = 27 ›  [改後|改前]│        │
├─────────┬─────────┬───────┤           │           [↶][↷]     ├────────┤
│ XY    ⤢ │ XZ    ⤢ │ YZ  ⤢ │           │                      │ XZ   ⤢ │
│         │         │       │           │   （可縮放、平移）     ├────────┤
└─────────┴─────────┴───────┘           │        [2.5× 1:1 8× 適合 對準選取] │ YZ ⤢ │
                                        └──────────────────────┴────────┘
```

- 狀態：`index.tsx` 一個 `const [big, setBig] = useState<Axis | null>(null)`。不寫進 localStorage；載入新檔案（`ed.orig` 換了）時回到 `null`。
- **入口**：每張小切面標題列最右邊一顆 `ExpandOutlined`（class `slice-zoom`，位置和完整版相同）。**不需要先選結構**（完整版要，因為那是進編輯）。已經有一張放大時，按另一張的放大鈕＝換成那一張。
- **出口**：主切面標題列的「← 回 3D」、小 3D 標題列的放大鈕、Esc（見下面的鍵盤）。
- **版面**：照搬完整版的 grid（`.canvas-area` 加 class `big-{axis}`、`.slices { display: contents }`）。寬 ≥ 1200 px：主切面在左、右邊一欄 `minmax(220px, 28%)` 由上到下是 3D、另外兩張切面；較窄時主切面在上排、3D 與另外兩張在下排。
- **主切面標題列**：「← 回 3D」、方向切換（XY 正面｜XZ 上視｜YZ 側面）、‹ 片數 ›、**「改後｜改前」與復原／重做**。後面這組現在放在 3D 標題列；放大時 3D 只剩 220 px 放不下，而且「改後｜改前」對切面一樣有作用，所以跟著主畫面走（抽成一段共用的 JSX，哪一格是主畫面就放哪一格）。
- **小 3D**：仍可轉、可點選、箭頭可拖；藏起左上角四行提示、視角列、底下說明列（完整版同樣藏掉）。
- **小切面**：行為不變（滾輪換片、點＝選取）。

**主切面的縮放與平移**（和完整版相同，除非特別註明）

| 操作 | 結果 |
|---|---|
| 滾輪 | 以滑鼠位置為中心縮放，範圍 0.25～32 px／體素 |
| Ctrl＋滾輪 | 換片（小切面仍是直接滾輪換片） |
| 右鍵拖、中鍵拖、空白鍵＋左鍵拖 | 平移 |
| **左鍵拖（新增）** | 平移。完整版左鍵拖是編輯把手；這裡唯讀，左鍵空著，拿來平移最順手 |
| 左鍵點一下（移動 < 4 px） | 選結構並把十字移到那裡；Shift／Ctrl＝多選（現有 `pickInSlice`） |
| 雙擊空白（空氣或圖外） | 適合視窗 |
| 右下角縮放列 | 目前倍率、`1:1`、`8×`、`適合`、`對準選取`（沒選結構時反灰） |

- 第一次放大某個方向＝適合視窗；之後這個方向記住上次的縮放與位置（回 3D 再進來還原）；載入新檔案時清掉。完整版還有「選取改變就自動對準」（設定抽屜的開關，預設開）；設定抽屜 v17 已經拿掉，這裡不做自動，要對準按縮放列的按鈕。
- 視窗、欄寬改變時保持畫面中心不動。
- 圖上畫的東西和小切面完全一樣：底圖（`drawSlice`）、拖箭頭時的即時結果（`SlicePreviewLayer`）、範圍虛線框、十字線。
- **鍵盤**：Esc 的順序＝拖拉中先取消拖拉 → 有選取先取消選取（現有，`editor.ts:657`）→ 都沒有才把放大的切面還原。其他鍵不變。

**程式放哪裡**

- 新檔 `src/pages/Section3D/SliceZoom.tsx`（估 200～250 行）：從完整版 `SliceEditor.tsx` 只搬上面列的「視圖變換」那幾段，節點、把手、ghost、手勢、浮動工具列、右鍵選單一律不搬。props 和 `SliceView` 相同，多一個 `selBox`（給「對準選取」）。
- `SliceView` 裡畫範圍框與十字線的 `<svg>`（`views.tsx:1681-1695`）抽成 `SliceOverlay`，兩個元件共用，不複製貼上。
- `SliceZoom` 不依賴 three.js，但放進 `views.lazy.tsx` 一起延後載入（它 import 的 `SliceOverlay` 在 `views.tsx`）。

## 5. 測試與驗收

單元測試（vitest）：
- `SliceZoom` 的純函式抽出來測：`fit`（圖置中、留邊）、`zoomAt`（縮放前後滑鼠下是同一個體素、夾在 0.25～32）、`aim`（選取的外框在畫面中央）、螢幕座標 ↔ 體素座標來回一致。
- 既有 233 個測試全過；`tsc -b`（`noUnusedLocals`）過。

e2e `m18.cjs`（1600×960 與 1280×720 各跑一次）：
1. 清空 localStorage 後開啟：不經任何點擊就出現 3D 與三張切面、左欄有結構、頂端列顯示「簡單範例」，沒有頁面錯誤；畫面上找不到歡迎頁的標題。
2. 頂端列「上傳 .vti」開得了對話框，按「複雜範例」會換成複雜範例。
3. 沒選任何結構，按 XY 的放大鈕：XY 變主畫面（寬度 > 3D 小窗）、3D 的 `<canvas>` 是同一個 DOM 節點（沒有重建）、另外兩張仍在。
4. 主切面上滾輪：縮放列的倍率變大，滑鼠下的體素不變；拖拉後圖移動；按「適合」回到整張；Ctrl＋滾輪 z 值變、倍率不變。
5. 主切面上點一個結構：選到它（`__ed.sel.size === 1`），拖了超過 4 px 則不選。
6. 選一個結構按「上面外推 1 格」：主切面上看得到結果；「改後｜改前」與復原在主切面標題列上可按。
7. Esc 第一次取消選取、第二次回到 3D 主畫面；回來後 3D 與三張切面的位置和寬度跟放大前逐 px 相同。
8. 換到 XZ 放大再回 XY：XY 的縮放與位置還在。

`m0.cjs`、`m17.cjs`、`perf.cjs` 改完開頭後照舊全過；`perf.cjs` 的一步時間不比 v17 §12.3 的數字差（這次沒有動到那條路徑，只是確認）。

## 7. 決策與待確認

| # | 決策 | 理由 | 要不要使用者確認 |
|---|---|---|---|
| D1 | 開啟時載入的是**簡單範例** | 「直接到主畫面」需要有模型可看；簡單範例最小、最快，也是 e2e 一直在用的 | **要**：如果想要的是複雜範例，或空的主畫面，改這一項就好 |
| D2 | 上傳保留在頂端列的對話框 | 需求只說「一開始不需要上傳的畫面」，沒說不要上傳 | 預設如此 |
| D3 | 放大不需要先選結構 | 現在只是看，不是進編輯 | 預設如此 |
| D4 | 放大時「改後｜改前」、復原／重做移到主切面標題列 | 小 3D 放不下；這三顆對切面一樣有用 | 預設如此 |
| D5 | 左鍵拖＝平移（完整版沒有） | 唯讀切面的左鍵拖沒有別的用途；右鍵／中鍵／空白鍵照樣可用 | 預設如此 |
| D6 | 不做「選取改變就自動對準」 | 它的開關在已經拿掉的設定抽屜裡；改用縮放列的「對準選取」 | 預設如此 |
| D7 | 小切面（沒放大的）不加縮放 | 完整版也沒有；小格子裡滾輪留給換片 | 預設如此 |

## 8. 不做的事

- 任何 2D 編輯（節點、把手、拖邊、右鍵選單、浮動工具列）。
- 主切面標題列上「滑鼠所在的座標與材質」讀數（完整版有；需要的話是之後的小項目）。
- 記住上次上傳的檔案、重新整理後還原。
- 觸控的雙指縮放。
