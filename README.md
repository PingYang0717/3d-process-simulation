# Section Editor 3D（簡化版）

在瀏覽器裡直接改 TCAD 輸出的 3D 材質體素（`.vti`，VTK ImageData；也接受 `.npy`）。v19 起畫面上沒有匯出（Worker 裡寫 `.vti` 的程式與測試還在）。這是 plan v17（`docs/plan-v17-simple-version.md`）的簡化版：只留**推拉一面、整塊平移、換材質**三個動作，沒有 split、沒有 2D 編輯；完整版留在 `claude/upbeat-einstein-wod16i` 分支。

最大原則：沒碰到的體素一個都不變；一步只會改變緊貼那一層的厚度，畫面事先寫出誰跟著、誰變薄、最多能推幾格。

## 開始

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 逐體素測試（vitest）
npm run build      # 型別檢查 + 打包
```

打開就是主畫面，已經載入**簡單範例**（plan v18：沒有歡迎頁）。要用自己的檔案按頂端列的「上傳 .vti」（`.vti`／`.npy`），同一個對話框也可以換範例：**簡單範例**（160×96×128，3 根 fin × 3 根 poly 閘極，HfO₂／TiN 包著 fin、SiN 蓋在 poly 上）、**複雜範例**（`demoComplex.ts`：三根寬高不同的 fin、三根 CD 不同的閘極＋spacer、SiGe S/D epi、W 接觸窗、ILD 與幾種缺陷）。

## 怎麼用

（需要的話先上傳檔案）→ 點一個結構（3D、切面或左邊的清單；Shift／Ctrl＋點＝多選同材質）→ 按「外推／內縮」、拖 3D 上的箭頭或按鍵盤。

- **收合**（v19）：左欄標題的「«」、右欄標題的「»」把那一欄收成一條窄邊，點窄邊展開；3D 下面的「2D 切面」橫條點一下展開／收合，**預設收起**。三個狀態都記在 localStorage。
- **畫面**：左欄依材質分組的結構清單；中間是可旋轉的 3D（上）與三張唯讀切面（下，展開後才有，XY 正面／XZ 上視／YZ 側面，‹ › 或滾輪換片，右上角的放大鈕把那一張換成主畫面）；右欄上半是動作面板、下半是「改了哪些」、最底下一行是上一步的說明＋復原。沒選結構時面板反灰。
- **選取**：點 3D、點切面、點清單都一樣；點空白＝取消。多選只收相同材質（不同材質不加入，會提示）；面板標題旁「選全部 Poly-Si（3）」或 Ctrl+A＝選同材質全部。選到之後其他結構半透明（0.40）、選到的照材質原色加藍色輪廓線，最後選的那個結構六個方向各一支橘色箭頭，旁邊標「上下左右前後」；箭頭貼在結構實際的表面上、離十字最近的那一格（v19；點哪裡箭頭就在哪裡附近，從清單選＝結構中央附近）。
- **材質開關**：清單的材質列整列點一下＝在 3D 顯示／隱藏（切面照常畫）；雙擊名字改名、點色塊改色；列尾的鎖＝整個材質固定／解除固定。
- **推拉一面**：選面（面板六顆按鈕、點 3D 上的箭頭、或方向鍵）→「上面內縮 1 格」「上面外推 1 格」；或在 3D 上順著箭頭拖＝外推、反方向＝內縮，游標旁即時顯示「上面外推 3 格（1.5 nm）」，放開完成。只動那個方向每一排最外側的表面；外面沒固定的結構全部跟著移動（v21，見下面的規則）。內縮到選到的結構會整個消失時先問：「只縮到還保留它」、「照做」或「取消」。
- **整塊平移**：六顆方向鍵按一下搬一次，或拖箭頭；形狀與大小不變。
- **換材質**：點一下就換；結構名字跟著材質重新編號（「SiN 1 換成 SiGe（現在叫 SiGe 1）」）。固定的結構不能換。
- **每次 n 格**：預設 1，旁邊寫等於幾 nm；按鈕、方向鍵、＋／－都用它。
- **固定**（v21／v22）：在結構上按**右鍵**（3D、切面、左邊清單、右欄「這一步會帶動誰」都可以；多選時在其中一個上按＝整批一起；右鍵拖仍是平移視角）→「固定位置（可被壓薄）」：不會被帶著走，被推到時變薄、最少留 N nm；或「完全鎖定」：形狀和位置都不變，別的結構推到它就停。固定的結構不能編輯（選到它只有一張「已固定」的卡片）、3D 上有深色線框、清單列尾有鎖。固定不算一步，不進復原。
- **固定的結構**（右欄中間）：目前鎖了誰、怎麼鎖；同材質同設定的合成一張卡片，可以直接切換「可被壓薄｜完全鎖定」、用 −／＋ 調最少保留的厚度、解除，或「全部解除」。
- **這一步會帶動誰**（推拉）：事先列出會跟著移動的結構與會被推到的固定結構（同材質合成一行，旁邊的鎖可以直接固定／解除；「把會跟著動的全部固定」方便先全鎖再解開想帶動的），以及「最多可外推 N 格（到 X 壓到最少厚度為止）」「最多可內縮 N 格（再多就會整個消失）」；推不動時按鈕反灰、寫出被誰擋，旁邊可以直接解除固定。
- **做完之後**：最底下一行與「改了哪些」寫出每個鄰居怎麼了，都寫出幾格（「Si fin 2 上面外推 2 格（1.0 nm）· HfO₂、TiN 跟著移動 2 格 · Poly-Si 變薄 2 格」）；沒做滿再加一句為什麼。「改了哪些」一步一筆，點一筆＝選回那一組結構；「全部還原」回到原始，它本身也可以復原。
- **看改動**：3D 標題列「改後｜改前」（切面放大時這一組和復原／重做移到主切面的標題列）。
- **放大切面**（plan v18，唯讀）：每張切面右上角的放大鈕，不必先選結構；它變成主畫面，3D 與另外兩張縮到旁邊的小窗（3D 仍可轉、可點、可拖箭頭）。主切面上滾輪＝朝游標縮放（0.25～32 px／體素）、Ctrl＋滾輪＝換片、拖拉（左鍵、右鍵、中鍵都可以）＝平移、點一下＝選結構、雙擊空白＝整張放進視窗；右下角縮放列有倍率、`1:1`、`8×`、適合、對準選取。每個方向記住上次的縮放。回 3D：「← 回 3D」、小 3D 右上角的按鈕、或 Esc。
### 鍵盤

| 鍵 | 推拉一面 | 整塊平移 |
| --- | --- | --- |
| ↑ ↓ ← →、PgUp（後）、PgDn（前） | 選那一面 | 往那邊搬一次 |
| ＋（或 =）／－ | 外推／內縮一次 | — |

共用：Esc 取消選取（拖到一半＝取消這次拖拉；沒有選取而且有切面放大時＝回 3D 主畫面）、Ctrl+Z 復原、Ctrl+Y 或 Ctrl+Shift+Z 重做、Ctrl+A 同材質全選、F 對準選取、H 全貌。方向鍵對應的是模型的上下左右前後（和箭頭上的字一致），不是螢幕方向。游標在輸入框、或開著對話框時不作用。

3D 視角：左鍵拖＝轉視角（旋轉中心先放到游標下）、滾輪朝游標縮放、右鍵拖＝平移、雙擊模型＝對準那一點、雙擊空白＝全貌；右下角視角列（正視／上視／側視／等角／全貌／對準選取）。

## 相鄰材質規則（plan v17 §5.4；v21 起不分薄層／厚層）

**沒固定的外層全部跟著平移；不想動的結構由使用者固定。**

外推一格時，對結構在那個方向每一排最外側的格子（切口）：往外一路到模型邊界、結構自己或固定的格子為止，這一串都是「跟著動的」（中間的空氣、空洞也算，所以隔著空氣的結構一樣整個平移）。位移由這一串**最外面那一格空的**吸收；沒有空的才輪到盡頭：

| 盡頭是 | 結果 |
| --- | --- |
| 模型邊界 | 最外面那個材質少一格（這一排至少要留 1 格，否則擋） |
| 可被壓薄的固定結構 | 它讓出一格；這一排不能少於它的最少厚度，到了就擋 |
| 完全鎖定的結構、結構自己 | 擋 |

**整面一起**：有一排被擋，這一格整面不做，整個動作停在已經做完的格數。**旁邊的排也跟著**：從每一排的切口往旁邊同一層，沿著「這幾排往外會帶動的材質」找相連、沒固定的格子，那一排也在同一層切開、照同樣的方式長一格或退一格——包在外面的整圈一起動，轉角保持包覆；一排可以從好幾層走到時取最外側那一層。這裡只看材質，不分是哪一個結構：旁邊相連的同材質結構也會在那一層被帶動，不想動就固定它。

內縮一格是外推的反向：切口那一格拿掉，外面那一串往內移一格；串裡有空的＝最外面那一格空的多一格；到模型邊界＝最外面那個材質補一格；盡頭是可被壓薄的固定結構＝它補回來；完全鎖定＝留空。可以一路縮到消失（面板會先問）。平移一格＝前面那一面外推一格＋後面那一面內縮一格。多格就是重複做一格；多選時每一格對每個結構依序做，大家停在同一格數。

裁切範圍（`preview.ts` 的 `adjacentBox`）：沿推的方向先多留 |n|＋24 格、側邊 4 格，實際算一次；有一排讀到範圍盡頭就放大重算（沿軸 ×4 → 模型邊界；側邊 32 格 → 整個平面）。外圍都固定時範圍小、一步很快；沒固定時跟著動的一路到模型邊界，範圍與改到的體素都大，大模型上一步會慢很多。試算（`probe`）有時間上限，超過就先回「至少 N 格」（N＋）。

代價：跟著動的結構如果只有一部分對到被推的面（其餘被固定的結構擋著、或在那一面的範圍之外），只有那一部分會動，結構會出現段差——把它固定就不會。

## 大陣列

所有 O(N) 的事都在 Web Worker：解碼、結構分析、每一步（只在外框裡算、原地貼補丁）、網格（切 chunk，一步之後只重算碰到的 chunk）、試算、匯出。主執行緒只貼補丁、差量更新 diff 與體積帳。第一次改之前要把原始抄一份當「目前」的帳簿，這一份在載入後的閒置時間分段先抄好。復原／重做存補丁（最多 50 步或 256 MB）。Worker 忙的時候最多再排 3 步；計算中可以取消。

量法：`npx vite-node scripts/bench.ts step 1 3`、`node scripts/e2e/perf.cjs http://localhost:5173 1 3`。數字與沒達到的目標見 plan v17 §12。
