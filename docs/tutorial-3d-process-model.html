3D 製程模型圖解

一頁看懂：模型裡每一格是什麼、前段閘極與後段 via 的形狀從哪裡來、哪些變化合理、哪些物理上做不出來、以及怎麼把它排成一組實驗。

1. 模型就是「每一格貼一張材質標籤」

把晶片切成一格一格的小方塊（每格 0.5～1 nm），每格存一個整數代表材質。沒有別的隱藏資訊：沒有時間、沒有溫度、沒有應力。形狀本身就是製程留下的歷史。

0 空氣1 Si 基板2 SiO₂（STI）3 Si fin4 HfO₂5 TiN6 Poly-Si7 SiN254 VOID

2. 前段（FEOL）：FinFET 閘極是怎麼長出來的

順序是：fin 立好 → 包一層 HfO₂（ALD，均勻包覆）→ 包一層 TiN → 填 Poly 蓋過 fin → CMP 削平 → 光罩＋蝕刻切成一條一條 → 兩側長 spacer。每一步只做四件事之一：沉積、蝕刻、研磨、改質。

可以怎麼變（合理的製程變異，每一個都說得出是哪一道製程偏了）

怎麼樣不行（物理上做不出來，模擬結果也沒意義）

換一個方向切：閘極長度 Lg（沿 fin 方向看）

3. 後段（BEOL）：via 與金屬線是「先挖洞再填」

後段的邏輯和前段相反，叫鑲嵌（damascene）：先鋪一整層 low-k 介電 → 蝕刻挖出 via 洞與溝槽 → 鋪一層很薄的 barrier（TaN／TiN）→ 電鍍銅填滿 → CMP 磨掉多餘的銅。

4. 怎麼排成一組實驗

核心只有一句：從標稱模型出發，一次只動一個變數，其他地方一格都不變，每個條件存成一個 split。

畫完一個形狀後的自我檢查
倒推一下：這個形狀是哪一道製程做出來的？
說得出「蝕刻多吃了 1 nm」「CMP 少磨了」「via 對位偏了 3 nm」→ 合理的變異。
說不出來（矽自己長高、薄膜只有一側、金屬沒有 barrier 直接貼介電）→ 通常是物理上做不出來的東西，下游結果不可信。
材質只能怎麼變不會發生
單晶矽（基板、fin）被蝕刻變小、磊晶長大沉積出來、自己長高
氧化物／氮化物薄膜沉積變厚、蝕刻變薄；熱氧化會吃掉矽閘極氧化層消失（那是短路）、只長一側
Poly／金屬閘高矮（CMP）、寬窄（蝕刻）、側壁角度長進 fin、穿過介電層
後段 Cu填滿或填不滿（void）、CMP 凹陷沒有 barrier 直接碰 low-k
