# 計畫 v7：以 2D 剖面編輯為主，3D 只看（可開關），每一步只算改到的地方

> 討論稿。對應的現況：plan v6／prototype v11 ＋ 本輪已合併的「即時預覽」「筆刷關閉」「補平成方頭」。
> 2D 編輯的操作形式參考 [process-simulation](https://github.com/PingYang0717/process-simulation)（PNG 剖面編輯器：區域輪廓、聰明游標、往外推、連帶襯層、畫面＝輸出）。

## 0. 一句話

在放大的切面上像改 PNG 一樣改結構的剖面，選一段範圍按套用，程式一片一片照規則寫進體素；3D 預設只用來看，雕刻要在設定裡打開；Worker 每一步只處理改到的那一塊，3D 只重畫碰到的 chunk，300×300×200 以上也能一步幾十毫秒。

## 1. 目標與不變的原則

目標

- 像 poly 補方頭、fin 加寬、spacer 變薄、recess 變深這類「剖面不變、沿一個軸拉長」的調整，在 2D 上一筆完成，可以打數字，套用前看得到每一片的結果。
- 3D 是看的：轉、縮、剖面、前後對照。要在 3D 上雕刻是進階功能，預設關閉。
- 1,800 萬 voxel（300×300×200）的檔案，一步從按下到 3D 更新完成 < 200 ms；5,300 萬（×3 範例）< 500 ms。

不變的原則（和 v6 相同）

- 沒碰到的體素一個都不變；每個操作直接改體素，不經過幾何近似。2D 上的多邊形只是「指定要改哪些格子」的工具，不是模型。
- 原始唯讀；所有改動都是可重播、可復原、會寫進 manifest 的 Op。
- 輸出 shape／dtype／spacing／origin 與原始相同。

## 2. 介面：2D 大、3D 小

版面

- 主畫面是**一張放大的切面**（預設 XY 正面；頂端 X／Y／Z 三個頁籤切方向，對應參考專案的三個方向槽）。上方一條**位置列**：目前在第幾片、◀ ▶、輸入框、nm，以及**套用範圍**（見 §4）。
- 右側一欄疊兩個小窗：另外兩張切面（跟著十字）和 3D 檢視。任一個小窗可以和主畫面對調（沿用現在的「放大」按鈕與 Esc）。
- 左欄結構清單、右欄「選取與調整／改動／Split」維持，但右欄的「長高／縮短」「補平」「移動」收成「數值調整」一區，主要操作改在切面上做。

3D 檢視的行為（預設）

- 左鍵拖＝轉、滾輪＝縮、右鍵拖＝平移、點一下＝選取、雙擊＝繞那點轉；沒有筆刷圈、沒有法線箭頭。
- 設定裡新增「**在 3D 上雕刻（進階）**」開關，預設關、記在 localStorage。打開後才出現現在的「筆刷」按鈕與推拉／補平行為；關著時 `brush.mode` 一律視為 `off`。

## 3. 2D 編輯：在切面上改剖面

### 3.1 從體素到可以拖的輪廓

每次切到一片、或選取改變時，對**已選結構在這一片的剖面**做一次（都是 2D、很快）：

1. 從 `labels` 取這一片屬於已選結構的格子 → 4 鄰接邊界鏈（移植參考專案 `raster/chains.ts` 的 `traceChains`）。
2. Douglas-Peucker 簡化（0.6 px），每一段記下原始像素輪廓；只有「角」當節點（`isCorner`：前後各走 6 px、夾角 ≥ 50°），圓角不會冒出一排把手。
3. 畫在切面上：藍線貼著像素邊，節點角畫方塊、其他畫圓點；只有已選結構顯示輪廓，游標滑過的結構顯示細框。

### 3.2 聰明游標（無模式，和參考專案一致）

| 游標靠近 | 游標樣式 | 拖動 | 等價的數值操作 |
| --- | --- | --- | --- |
| 節點 | 十字 | 拖節點，左右兩個節點之間的輪廓依 cos 衰減跟著走；Shift 只動這一點 | 右欄直接填 X／Y |
| 邊 | 雙箭頭 | 整段平滑邊沿法線推（兩端的角是錨點）；Shift 只推單一小段 | 浮動工具列「往外推 N vx」 |
| 區域內部 | 四箭頭 | 整個剖面在這一片的平面上搬動 | 方向鍵、右欄 Δ |
| 空白 | 預設 | 框選 | — |

拖動規則

- **連帶襯層**（預設開，對應設定裡現有的「襯層一起推」）：貼在外面、厚度均勻（≤ LINER_MAX，目前 4 格）的薄層跟著位移，最多 3 層；狀態列顯示「連帶 N 層」。
- **防穿層**（連帶關掉時）：位移逐步縮小，直到與鄰居至少留 1 格；狀態列顯示「已擋住」。
- 拖的時候就看到結果：拖動中每一步算出這一片的新格子（§3.3），用本輪的即時預覽路徑（`previewOp` 的 2D 版）即時畫在主切面、兩張小切面和 3D 上。

浮動工具列（選到結構時出現在外框旁）

- **方頭**：這一片裡每一欄從現在的頂面補到最高點（就是 `levelMask` 的 2D 版，一鍵）。方向可選（上／下／左／右）。
- **往外推 N vx…**：已選邊沿法線推，負值往內。
- **移動…**、**換材質**、**設為 VOID**。
- **套用到**：此片／目前範圍／整個結構（§4）。
- 右鍵選單依點到的是區域、節點、邊給不同項目（同參考專案）。

### 3.3 畫面＝輸出：多邊形 → 這一片的格子

拖完的輪廓要變回格子，用參考專案 `exportRaster` 的做法，保證沒動的地方逐像素相同：

- 沒動的段落沿用原始像素輪廓；兩端位移不同的段落沿輪廓長度內插位移；只有新插的頂點用直線。
- 整塊整數位移 → 直接搬格子。
- 像素中心掃描線填色、不反鋸齒。
- 結果和這一片原本的剖面比對，得到 **add**（要變成這個結構的格子）與 **remove**（要拿掉的格子）兩組，每個 add 格子帶一個「來自哪條邊、法線朝哪」的方向碼（上下左右），襯層跟推用。

## 4. `profile` Op：一片的改動掃過一段

```ts
type Op = … | {
  kind: 'profile';
  keys: string[];              // 已選結構
  axis: Axis;                  // 切面的法線軸（XY 正面 = 'z'）
  at: number;                  // 參考片（在哪一片畫的）
  range: [number, number];     // 套用到哪一段（含端點）
  add: Rle2D;                  // 相對結構外框的 2D RLE，每格含方向碼
  remove: Rle2D;
  follow: boolean;             // 襯層跟推
  backfill: Backfill;          // 拿掉的格子填什麼（'orig' 或材質編號）
  mirror?: string[];           // 同時套到這些「長得一樣」的結構（§4.3）
};
```

### 4.1 範圍

- 預設＝**這個結構沿法線軸的整個長度**（fin 就是整根；poly 就是整條）。
- 位置列上的範圍控制：「此片」「從這片到那片」（拖兩個端點，或在兩片各按一次「設為起點／終點」）「整個結構」。這取代現有的「只改其中一段（z）」，並推廣到三個軸。
- 範圍在畫面上看得到：主切面的位置列標出範圍，3D 上用藍色半透明標出會被改到的部分（沿用現有 `affMask`）。

### 4.2 逐片規則（一段裡有些地方不一樣時會發生什麼）

每一片各自做、互不影響：

1. **add 格子**：這一片該位置是空氣 → 填；是薄襯層 → 沿方向碼把襯層整列推開再填（同 `growMask`／本輪的 `levelMask follow`）；是厚的別的材質 → 不動，記成「被擋住」。
2. **remove 格子**：只拿掉**這個結構自己的**體素，別人的不碰；空出的地方回填 `backfill`。
3. **只加不減**：沒畫到的格子一律不動。某一片本來就比較高、比較胖，維持原樣；要削才明確畫擦除。
4. **連在一起才填**：add 格子依「離原本邊界的距離」由近到遠處理，必須和這一片已有的結構 4 鄰接才填；這一片根本沒有這個結構的欄位就跳過。不會憑空長出飄在空中的一截。
5. **報告**：回傳每一片的 `{filled, pushed, blocked, skipped}`。套用前的預覽把摘要寫在位置列（「z 40～80 共 41 片：37 片完整套用，4 片有 12 格被 Poly-Si 擋住」），被擋的格子在切面上標紅，位置列上有紅點可以直接跳過去看。

「照剖面取代」（多的削掉、少的補上）做成一個預設關閉的開關，因為它會抹平真實資料的細節，而且有別的材質卡住時也取代不了。

### 4.3 對應到長得一樣的結構

選了三根 fin、在其中一根上改，其他兩根一起改。做法移植參考專案 `editor/mirror.ts` 的 `counterparts`：座標正規化到各自外框的 [0,1]²，找最近的節點（門檻 0.12）或邊（門檻 0.2）。套用時每個結構各自算自己的 add／remove（所以三根 fin 位置不同也沒關係）。可在浮動工具列關掉。

### 4.4 相對式套用（第二階段）

v1 的 add／remove 是以參考片的座標為準，掃過整段。結構在一段裡微微偏移時會差一格。第二階段把 Op 裡多存「這一筆是對哪條邊做了什麼」（例如「頂邊往外 3」），每一片先追自己的輪廓、用 §4.3 的對應找到同一條邊、重做一次再轉成格子；對不到的片退回 v1 的做法並在報告裡標出。這一步不改 Op 的外部格式，只是多一個欄位。

## 5. 效能：每一步只處理改到的地方

現況的瓶頸不是 2D 或 3D，而是每一步都對整個陣列做 O(N)：複製整個陣列、掃整個陣列找改動外框、整個陣列重做 greedy mesh、再掃一次算 diff 與體積帳。改法四件事，彼此獨立、都在 Worker。

### 5.1 Op 只在外框裡算

- 本輪 `previewBox` 已經會算「這一步會動到的外框」。Worker 的 `replay` 改成同樣先算外框，只在外框裡跑 `growMask`／`levelMask`／`translateMask`／`profile`，結果寫回整個陣列的複本（18 MB 的 memcpy 只要幾毫秒，慢的是迴圈）。
- `relabel` 直接拿到外框，跳過第一步「掃整個陣列找不同」。
- 測試：外框內外的結果和現在全陣列版本逐體素相同（`preview.test.ts` 已有同型的測試，擴到所有 Op）。

### 5.2 復原存補丁

- 每一步只存 `{bbox, before, after}` 兩塊小陣列，不存整個狀態。Worker 復原＝把 `before` 貼回去；重做＝貼 `after`。
- 18M 的檔案每步從 18 MB 降到通常幾百 KB；`HISTORY_LIMIT` 可以從 10 放寬到 50。

### 5.3 3D 網格切 chunk

- 體素空間切成 32³（或 64³，依大小自動）的 chunk，每個 chunk 自己 greedy mesh（跨 chunk 的面不合併，矩形數多一到兩成，可接受）。
- Worker 保存目前 split 每個 chunk 的網格；一步之後只重算與改動外框（外擴 1 格）相交的 chunk，只把這些 chunk 的三角形送回主執行緒。
- 主執行緒每個 chunk 一個 `Mesh`（或一個大 geometry 用 draw range 分段），BVH 每個 chunk 一個；點選對所有 chunk 做 raycast（three-mesh-bvh 很快）。
- 隱藏材質、改顏色、切差異模式仍要全部重算，但這些不是編輯迴圈裡的動作。切 split 用每個 split 的 chunk 快取（LRU 留 3 個）。
- 做完這項，本輪的「即時預覽」在 3D 上就不再需要（正式網格本身就幾十毫秒），只留切面的預覽路徑給拖動中的即時回饋。
- 測試：所有 chunk 的面積和＝全陣列 greedy mesh 的面積和（現有「面積和逐體素暴露面相同」的測試改成 chunk 版）。

### 5.4 diff 與體積帳用差量

- Worker 在每一步的外框裡更新 diff mask 與每材質計數，不再掃整個陣列；`count` 與 `diff` 直接回傳快取。

### 5.5 目標數字

以 ×3 範例（5,300 萬）實測等比例推算：

| 檔案 | 現在：套用＋relabel | 現在：重畫 3D | 目標：一步到 3D 更新完 |
| --- | --- | --- | --- |
| 160×96×128（197 萬） | 0.3～0.5 s | 0.3 s | < 50 ms |
| 300×300×200（1,800 萬） | 2～3 s | 1.5 s | < 200 ms |
| 480×288×384（5,300 萬） | 5～7 s | 4.5 s | < 500 ms |

載入與第一次標記結構不變（一次性）。

## 6. 里程碑與驗收

每個里程碑都可以獨立合併、獨立用。

**M0 版面與開關（小）**

- 2D 大、3D 小的版面；X／Y／Z 頁籤；「在 3D 上雕刻」開關（預設關）。
- 驗收：關著時 3D 上怎麼拖都只轉視角；開著時行為和現在一樣。

**M1 Worker 區域性運算與 chunk 網格（基礎）**

- §5.1～5.4 全部。
- 驗收：300×300×200 的檔案上，長高 1 格從按下到 3D 更新完 < 200 ms；復原 10 步記憶體不再隨陣列大小成長；測試：外框內外逐體素相同、chunk 面積和相同、補丁復原＝快照復原。

**M2 2D 編輯核心**

- §3.1～3.3、§4.1～4.2：輪廓與節點、聰明游標三種拖法、往外推 N、方頭、範圍控制、`profile` Op、逐片規則與報告、拖動中即時預覽。
- 驗收：範例裡選 fin 1、在正面切面按「方頭」、套用到整根，結果和本輪右欄「補平成方頭」逐體素相同（768 格）；掃過閘極底下時襯層被推開、報告裡 blocked = 0；範圍縮到閘極之間時 blocked 也是 0 且閘極底下不變。測試：沒動的輪廓重新光柵化逐格相同、連通保險、逐片報告數字。

**M3 友善化**

- 浮動工具列、右鍵選單、數值輸入（節點 X／Y、邊往外推、區域 Δ）、前後對照（沿用 B 鍵與差異模式）、對應到長得一樣的結構（§4.3）、說明與 README、把右欄舊的三個調整區收成「數值調整」。
- 驗收：第一次用的人照說明三步內完成「三根 fin 一起補方頭」。

**M4 相對式套用（可選）**

- §4.4。驗收：人工做一條在 z 方向偏移 1 格的 fin，頂邊往外 3 掃過整根，每一片都剛好多 3 格、blocked = 0。

建議順序 M0 → M1 → M2 → M3 → M4。M1 和 M2 互不相依，手夠的話可以並行。

## 7. 要你決定的幾件事

1. 主切面預設哪一個方向？（草稿：XY 正面，因為 fin 剖面在這裡。）
2. 套用範圍預設「整個結構」還是「此片」？（草稿：整個結構；只改一片的情況比較少，而且範圍一直顯示在位置列上。）
3. 對應到長得一樣的結構預設開還是關？（草稿：開，選了多個結構時才有作用。）
4. 拿掉格子時預設回填原始內容還是 VOID？（草稿：原始內容，和現在一樣；參考專案預設 VOID 是因為 PNG 沒有「原始」可回填。）
5. 3D 雕刻開關放設定裡，還是 3D 工具列上一個明顯的開關？（草稿：設定裡，工具列只在開著時顯示「筆刷」。）
