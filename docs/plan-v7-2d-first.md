# 計畫 v7.1：以 2D 剖面編輯為主，3D 只看（可開關），每一步只算改到的地方

> 討論稿第二版。對應的現況：plan v6／prototype v11 ＋ 已合併的「即時預覽」「筆刷關閉」「補平成方頭」。
> 2D 編輯的操作形式參考 [process-simulation](https://github.com/PingYang0717/process-simulation)（PNG 剖面編輯器：區域輪廓、聰明游標、往外推、連帶襯層、畫面＝輸出）。
> v7.1 相對 v7.0 的修訂列在 §9。

## 0. 一句話

在放大的切面上像改 PNG 一樣拖結構的剖面，每拖一下就立刻套用到你設定的那一段（預設整根），不對就復原；3D 預設只用來看，雕刻要在設定裡打開；Worker 每一步只處理改到的那一塊，3D 只重畫碰到的 chunk，300×300×200 以上也能一步幾十毫秒。

## 1. 目標與不變的原則

目標

- poly 補方頭、fin 加寬、spacer 變薄、recess 變深這類「剖面不變、沿一個軸拉長」的調整，在 2D 上一筆完成，可以打數字，做完立刻看到整段的結果與哪裡被擋住。
- 3D 是看的：轉、縮、剖面、前後對照。3D 雕刻是進階功能，預設關閉。
- 1,800 萬 voxel（300×300×200）的檔案，一步從放開滑鼠到 3D 更新完成 < 200 ms；5,300 萬（×3 範例）< 500 ms。

不變的原則（和 v6 相同）

- 沒碰到的體素一個都不變；每個操作直接改體素，不經過幾何近似。2D 上的多邊形只是「指定要改哪些格子」的工具，不是模型。
- 原始唯讀；**每一個手勢就是一個 Op**，立刻套用、可重播、可復原、寫進 manifest。沒有「先畫再按套用」的中間狀態。
- 輸出 shape／dtype／spacing／origin 與原始相同。

## 2. 介面：2D 大、3D 小

### 2.1 版面

- 主畫面是**一張放大的切面**。頂端 X／Y／Z 三個頁籤切方向（預設 XY 正面）。選到結構時，頁籤上顯示它在那個方向的尺寸，例如「上視 XZ · 可改 z 72 vx」，提醒「要改 z 方向的厚度請切到上視」（在 XY 上改不了閘極長度）。
- 主切面上方一條**位置列**：目前第幾片（◀ ▶、輸入框、nm）＋ **套用範圍**（§4.1）。這是唯一的範圍控制。
- 右側一欄疊兩個小窗：另外兩張切面（跟著十字）和 3D 檢視。任一個小窗可以和主畫面對調（沿用「放大」按鈕與 Esc）；**哪個窗放大會記在 localStorage**，喜歡 3D 大的人不用每次重設。
- 左欄結構清單維持。右欄「選取與調整」改成：尺寸、材質、**範圍（和位置列是同一個狀態，兩處顯示同一個控制）**、數值調整（長高／縮短、往外推、移動、方頭）。

### 2.2 主切面的縮放與平移

- **滾輪＝縮放（朝游標）**，不再是換片。換片用 ◀ ▶、`,` `.`、PgUp／PgDn，或 Ctrl＋滾輪。
- 平移：右鍵拖，或空白鍵＋左鍵拖（觸控板沒有中鍵）。
- 右下角縮放列：1:1／8×／適合視窗／**對準選取**。選到結構時預設自動放大到它（含邊距），設定裡可關。
- fin 在整張切面裡只有幾十像素寬，不放大就抓不到邊，所以這一節是 2D 編輯能用的前提。

### 2.3 3D 檢視

- 預設：左鍵拖＝轉、滾輪＝縮、右鍵拖＝平移、Alt＋左鍵拖＝轉（觸控板）、點一下＝選取、雙擊＝繞那點轉。沒有筆刷圈、沒有法線箭頭。
- 設定裡新增「**在 3D 上雕刻（進階）**」開關，預設關、記在 localStorage。3D 小窗的標題列放一個小標籤「3D 雕刻：關」，點了直接跳到那一項設定；開著時標籤變成「3D 雕刻：開」，工具列才出現「筆刷」按鈕，行為同現在。
- 3D 上永遠用藍色半透明標出「目前範圍內會被改到的部分」（沿用 `affMask`），這是 §4.1 範圍提示的一部分。

## 3. 2D 編輯：在切面上改剖面

### 3.1 從體素到可以拖的輪廓

每次切到一片、或選取改變時，對**已選結構在這一片的剖面**做一次（都是 2D，300×300 以內不到 1 ms）：

1. 從 `labels` 取這一片屬於已選結構的格子 → 4 鄰接邊界鏈（移植參考專案 `raster/chains.ts` 的 `traceChains`）。**支援內環（poly 裡的 VOID 缺陷在剖面上是一個洞）與多環（U 形結構在某一片是兩塊）**：一個結構在一片上＝一組環，每個環各自描、各自可拖。
2. Douglas-Peucker 簡化（0.6 px），每一段記下原始像素輪廓；只有「角」當節點（`isCorner`：前後各走 6 px、夾角 ≥ 50°），圓角不會冒出一排把手。
3. 畫在切面上：藍線貼著像素邊，節點角畫方塊、其他畫圓點；只有已選結構顯示輪廓，游標滑過的結構顯示細框。
4. 這一片沒有這個結構時，位置列顯示「這一片沒有 Si fin 1 · 跳到最近的一片（z = 14）」。

### 3.2 聰明游標（無模式）

| 游標靠近 | 游標樣式 | 拖動 | 等價的數值操作（右欄） |
| --- | --- | --- | --- |
| 節點（8 px 內） | 十字 | 拖節點，左右兩個節點之間的輪廓依 cos 衰減跟著走；Shift 只動這一點 | 節點 X／Y |
| 邊（6 px 內） | 雙箭頭 | 整段平滑邊沿法線推（兩端的角是錨點）；Shift 只推單一小段 | 往外推 N vx |
| 區域內部 | 四箭頭 | 整個剖面在這一片的平面上搬動 | Δ 位移 |
| 空白 | 預設 | 框選 | — |

- **熱區優先順序固定：節點 > 邊 > 區域**，門檻以螢幕像素計、不隨縮放變。按住 V／E／R 強制只抓節點／邊／區域（同參考專案）。
- **方向鍵**：選到節點或邊時推它 1 格（Shift 10 格）；只選結構沒選把手時才是整塊移動（現有行為）。
- **鍵盤等價**：右欄的三組數值輸入（節點 X／Y、邊往外推 N、區域 Δ）和拖拉產生完全相同的 Op，不用滑鼠也做得到同一件事。
- **第一次使用**：選到結構後左下角出現三行提示「靠近點可以拖、靠近邊可以推、在裡面可以搬」，成功拖過一次就不再出現；`?` 說明裡可重看。

拖動規則

- **連帶襯層**（預設開，就是設定裡現有的「襯層一起推」）：貼在外面、厚度 ≤ LINER_MAX（4 格）的薄層跟著位移，最多 3 層；狀態列顯示「連帶 N 層」。
- **防穿層**（連帶關掉時）：位移逐步縮小，直到與鄰居至少留 1 格；狀態列顯示「已擋住」。
- **拖的時候就看到結果**（分三級，§4.4）。

### 3.3 手勢 → Op：能用舊 Op 就用舊 Op

每個手勢放開時變成一個既有的 Op，只有既有 Op 表達不了的才用新的 `profile`。這樣逐片規則只有一套、測試也沿用。

| 手勢 | Op | 說明 |
| --- | --- | --- |
| 推一條**和軸平行的整段邊**（fin 頂邊、側邊） | `push`（dir＝邊的法線，n＝格數，scope＝範圍） | 和 3D 的整面推拉是同一件事：那條邊掃過範圍就是那一面 |
| 搬整個剖面 | `translate`（d 在平面內，scope＝範圍，**follow**） | §4.2 第 3 條 |
| 浮動工具列「方頭」 | `level`（radius null，to＝這個方向最外側，scope＝範圍） | 已有，而且是「每一欄各自補到頂」的相對做法，結構微微偏移也對 |
| 拖節點、推一段不完整的邊、推斜邊或圓弧、擦除一塊 | `profile` | §4 |
| 換材質、設為 VOID | `material` | 已有 |

### 3.4 畫面＝輸出：多邊形 → 這一片的格子（`profile` 用）

用參考專案 `exportRaster` 的做法，保證沒動的地方逐像素相同：

- 沒動的段落沿用原始像素輪廓；兩端位移不同的段落沿輪廓長度內插位移；只有新插的頂點用直線。
- 像素中心掃描線填色、不反鋸齒；所有頂點取整數格。
- 結果和這一片原本的剖面比對，得到 **add**（要變成這個結構的格子）與 **remove**（要拿掉的格子），每個格子帶一個方向碼（上下左右，來自它所屬的邊的法線），襯層跟推／跟退用。

## 4. 範圍、逐片規則、`profile` Op

### 4.1 範圍（Scope）：所有工具共用的一個狀態

```ts
interface Scope { axis: Axis; lo: number; hi: number }   // 取代所有 Op 裡的 zRange
```

- **取代現有的 `zRange`**：push／translate／material／level／profile 全部改用 `scope`，意義不變＝「只有 scope 裡的體素可以被改」。舊 Op 的 `zRange` 讀進來時轉成 `{axis:'z', lo, hi}`。
- 一個狀態、兩處顯示：位置列與右欄「範圍」是同一個控制。3D 筆刷、數值調整、2D 手勢都吃它。
- 三種模式：**整個結構**（預設；選取改變時自動重算成新結構沿 scope 軸的整個長度）、**此片**（跟著目前片）、**自訂**（雙把手滑桿，標出結構的起止，顯示「z 40～80 · 41 片 · 20.5 nm」）。模式記在 localStorage，自訂的端點是絕對座標、換結構時夾在它的範圍內。
- scope 的軸＝目前主切面的法線軸。切頁籤時 scope 軸跟著換，模式不變。

範圍一定要看得到（這三件是 M2 的驗收條件，缺一不可）：

1. 位置列永遠寫著目前範圍，例如「套用到：整根（z 0～127）」。
2. 3D 上藍色半透明標出會被改到的部分；主切面上在範圍外的片，輪廓用灰色虛線並在位置列顯示「這一片不在範圍內」。
3. 每一步的訊息寫明範圍：「Si fin 1 頂邊往外 3 vx · 已套用到整根（z 0～127）· 復原」。
4. 按鈕文字帶範圍詞：「方頭（整根）」「方頭（此片）」「方頭（z 40～80）」。

### 4.2 逐片規則（一段裡有些地方不一樣時會發生什麼）

每一片各自做、互不影響。四條規則是**所有 Op 共用的一套核心**（`growMask`／`levelMask`／`translateMask`／`profile` 都走它），不會有兩種結果：

1. **加格子**：該位置是空氣 → 填；是薄襯層且 follow → 沿方向碼把襯層整列推開再填；是厚的別的材質 → 不動，記成 blocked。
2. **拿格子**：只拿這個結構自己的體素，別人的不碰；空出的地方回填 `backfill`。**follow 時外側的薄襯層跟著退回來**（同本輪 `levelMask` 削平的做法），不會留下懸空的 HfO₂ 和一條回填。
3. **搬格子（translate）**：follow 時，貼在結構外面的薄層殼一起搬（每個邊界格沿它的外法線 `collectLiners` 收到的格子＝殼）；搬到的地方照 growMask 的規則覆蓋，空出的地方回填。3D 的「整塊移動」改成同一個實作，2D 區域拖動與 3D 移動結果一致。
4. **只加不減、連在一起才填**：沒畫到的格子一律不動（某一片本來比較高就維持）。add 格子依「離原本邊界的距離」由近到遠處理，必須和這一片已有的結構 4 鄰接才填；這一片沒有這個結構就整片跳過，不會憑空長出飄在空中的一截。

報告：每一片回傳 `{filled, pushed, blocked, skipped}`。套用後的訊息寫摘要「z 40～80 共 41 片：37 片完整，4 片有 12 格被 Poly-Si 擋住 · 看這些片 · 復原」；被擋的格子在切面上標紅、位置列上有紅點可以直接跳過去。

「照剖面取代」（多的削掉、少的補上）做成預設關閉的開關，因為它會抹平真實資料的細節，而且有別的材質卡住時也取代不了。

### 4.3 `profile` Op

```ts
type Op = … | {
  kind: 'profile';
  keys: string[];              // 已選結構（多個時各自算自己的 add／remove）
  scope: Scope;                // axis 就是切面的法線軸
  at: number;                  // 參考片（在哪一片畫的）
  add: Rle2D;                  // 相對結構外框的 2D RLE，每格含方向碼
  remove: Rle2D;
  follow: boolean;
  backfill: Backfill;
  text?: string;               // 白話描述，例如「頂邊往外 3 vx」，manifest 與改動清單用
};
```

- 只在 scope 裡的片套用；每片走 §4.2。
- `opText`：「Si fin 1（XY，z 0～127）頂邊往外 3 vx」。
- 一個結構在一片裡有多個環時，add／remove 是整片的集合，不分環。

### 4.4 即時回饋分三級

1. **正在改的主切面**：永遠即時。拖動中只對這一片算 §4.2（純 2D，< 1 ms），畫面就是結果，狀態列顯示連帶層數或已擋住。
2. **3D 與另外兩張小切面**：改到的外框 × 範圍 ≤ 40 萬格時即時（本輪的 `previewOp` 路徑）；超過就放開後再更新。
3. **放開後**：立刻送 Worker，M1 之後整段在 < 200 ms 內成為正式結果。

### 4.5 大操作的保護與排隊

- scope 內會處理的體素 > 400 萬（例如選到基板或 STI 按方頭）：先問一句「這一步會改到約 N 萬格，可能要幾秒，繼續？」。
- Worker 正在算時再來的手勢**排隊**（FIFO，最多 3 個），不再像現在直接丟掉；位置列顯示「排隊 2 步」，排隊中的手勢只有主切面即時、其他等它輪到。

### 4.6 對應到長得一樣的結構

選了三根 fin、在其中一根上改，其他兩根一起改。移植參考專案 `editor/mirror.ts` 的 `counterparts`（座標正規化到各自外框的 [0,1]²，最近的節點門檻 0.12、邊門檻 0.2）。**保險**：只對同材質、外框長寬比相差 ≤ 20%、面積相差 ≤ 30% 的結構配對，避免 poly 和 fin 這種都是長方形的互配；浮動工具列可關。套用時每個結構各自算自己的 add／remove，位置不同也沒關係。

### 4.7 相對式套用（M4）

v1 的 add／remove 以參考片座標為準掃過整段，結構在一段裡偏移 1 格時那幾片會差一格。M4 在 Op 多存「對哪條邊做了什麼」（例如「頂邊往外 3」），每片先描自己的輪廓、用 §4.6 的對應找同一條邊、重做一次再轉成格子；對不到的片退回 v1 並在報告裡標出。不改 Op 的外部格式，只多一個欄位。注意 §3.3 已把最常見的三種手勢對到相對做法的舊 Op，M4 只影響 `profile`。

## 5. 效能：每一步只處理改到的地方

現況瓶頸不是 2D 或 3D，而是每一步都對整個陣列做 O(N)：複製整個陣列、掃整個陣列找改動外框、整個陣列重做 greedy mesh、再掃一次算 diff 與體積帳。改法五件事，都在 Worker 或 client 層。

### 5.1 先做：狀態用版本號，不再用陣列身分

現在 `sidOf`、`diffCache`、`countCache`、網格快取都用「這個 `Uint8Array` 是不是同一份」當 key。一旦改成只傳補丁，這套判斷全部失效。所以 M1 的第一步是：

- 每個 `EditState` 帶 `version: number`（單調遞增），主執行緒與 Worker 都用它當 key；`ensure`／`retain`／`cached` 全部改掉。
- 這一步本身不改任何行為，先合併、先過測試，再動其他的。

### 5.2 Op 只在外框裡算

- `previewBox` 已會算「這一步會動到的外框」。Worker 的 `replay` 改成同樣先算外框，只在外框裡跑核心，結果寫回整個陣列的複本（18 MB memcpy 幾毫秒；慢的是迴圈）。
- `relabel` 直接拿到外框，跳過第一步「掃整個陣列找不同」。
- 回傳主執行緒的是**補丁**（外框＋外框內的新資料）；主執行緒把目前陣列 memcpy 一份、貼上補丁，成為新版本。主執行緒永遠有每個 split 目前的完整陣列（切面繪圖與點選要用），但**復原不再存整份**（5.3）。

### 5.3 復原存補丁

- 每一步只存 `{bbox, before, after}`。復原＝memcpy 目前陣列、貼回 `before`；重做＝貼 `after`。主執行緒與 Worker 各做一次（Worker 裡的常駐狀態同步更新，不必 `put` 整份）。
- 18M 的檔案每步從 18 MB 降到通常幾百 KB；`HISTORY_LIMIT` 從 10 放寬到 50。

### 5.4 3D 網格切 chunk

- 體素空間切成 32³ 的 chunk（陣列 > 3,000 萬時 64³），每個 chunk 自己 greedy mesh（跨 chunk 的面不合併，矩形數多一到兩成；同一平面上的兩個矩形不會有接縫）。
- Worker 保存目前 split 每個 chunk 的網格；一步之後只重算與改動外框（外擴 1 格）相交的 chunk，只傳這些 chunk 回主執行緒。
- 主執行緒每個 chunk 一個 `Mesh` 與一個 BVH；點選對所有 chunk raycast。
- 隱藏材質、改顏色、切差異模式仍要全部重算（不在編輯迴圈裡）。切 split 用每個 split 的 chunk 快取（LRU 留 3 個）。

## 6. 里程碑、順序與驗收

**順序固定：M0 → M1 → M2 → M3 → M4。M1 是 M2 的前置條件**，因為「每拖一下就立刻套用到整根」要夠快才能用，而且現在計算中的手勢會被丟掉。

**M0 版面與開關（小）**

- 2D 大、3D 小的版面（可對調、記住）；X／Y／Z 頁籤；主切面滾輪縮放、換片改鍵；「在 3D 上雕刻」開關與 3D 標籤；Scope 取代 zRange（§4.1 的資料結構與單一控制，先只接現有工具）。
- 驗收：關著時 3D 上怎麼拖都只轉視角；開著時行為和現在一樣。現有 44 個測試照過；舊 Op 的 zRange 轉 scope 後重播結果逐體素相同。

**M1 Worker 區域性運算與 chunk 網格（M2 的前置）**

- §5.1～5.5 全部，依 5.1 → 5.2 → 5.3 → 5.4 → 5.5 的順序各自合併。
- 驗收：300×300×200 上長高 1 格從放開到 3D 更新完 < 200 ms；復原 10 步的記憶體不隨陣列大小成長；測試：外框內外逐體素與全陣列版相同、chunk 面積和＝全陣列 greedy mesh 面積和、補丁復原＝快照復原、版本號改造前後所有快取命中行為相同。

**M2 2D 編輯核心**

- §3.1～3.4、§4.1～4.5：輪廓與節點（含內環、多環）、聰明游標三種拖法、手勢對 Op 的對應表、往外推 N、方頭、範圍控制與三項提示、`profile` Op 與逐片規則（含拿格子跟退、搬格子帶殼）、報告與「看這些片」、三級即時回饋、大操作確認、排隊。
- 驗收：
  - 範例裡選 fin 1、XY 正面按「方頭（整根）」，結果和現在右欄「補平成方頭」逐體素相同（768 格），blocked = 0（閘極底下襯層被推開）；範圍縮到閘極之間，閘極底下不變。
  - 推 fin 1 頂邊往外 3，產生的是 `push` Op，和 3D 整面長高 3 格逐體素相同。
  - 削 fin 1 頂邊往內 2（follow 開），HfO₂／TiN 跟著降 2 格，沒有懸空層。
  - 搬 fin 1 往右 2（follow 開），襯層殼一起搬，原位回填原始。
  - 一片沒有這個結構時整片 skipped；add 格子不連通時不填。
  - 測試：沒動的輪廓重新光柵化逐格相同、內環與多環描得出來、連通保險、逐片報告數字、排隊不丟手勢。

**M3 友善化**

- 浮動工具列、右鍵選單、數值輸入（節點 X／Y、邊往外推、區域 Δ，與拖拉等價）、第一次使用提示、前後對照（沿用 B 鍵與差異模式）、對應到長得一樣的結構（§4.6 含保險）、說明與 README、頁籤上的各方向尺寸提示。
- 驗收：第一次用的人照左下角提示，三步內完成「三根 fin 一起補方頭」；不用滑鼠也能用右欄數值做到同一件事並得到相同 Op。

**M4 相對式套用（可選）**

- §4.7。驗收：人工做一條在 z 方向偏移 1 格的 fin，用 `profile` 推斜邊往外 3 掃過整根，每一片都剛好多 3 格、blocked = 0。
