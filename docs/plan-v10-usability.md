## 0. 一句話

3D 的旋轉中心永遠落在模型上、滾輪朝游標下的實際表面縮放；2D 拖角預設像拖矩形的角（相鄰兩條直邊跟著平移），自由變形改成修飾鍵；
「現在」畫面不再把改過的體素染紅，要看差異切「差異」；所有數值操作先在畫面上畫出淡綠／淡紅的結果、按「套用」才真的改；
選一個結構按 E 進入**聚焦編輯**：其他結構半透明、結構上長出面把手（整面長／縮）與角把手（圓頭），不在把手上拖永遠是轉視角，筆刷變成模式裡的一個工具；
圓頭是一個帶參數的 Op（哪些角、半徑、方圓度、肩高／不對稱、凹角），2D／3D 開同一個面板、拖滑桿即時預覽；
介面上同一個操作只剩一個名字、一個面板，標題列只放「怎麼看」，右欄與 2D 浮動列共用同一組卡片。

## 3. 原則、不做的事

- **體素規則不動**：`kernel.ts`／`apply.ts`／`patch.ts`／`profile.ts` 的套用邏輯一行不改；`round` 走 profile 的 add／remove 路徑，仍由 kernel 決定填不填。
- **同一個 Op 只有一條產生路徑**：拖把手、打數字、方向鍵、右鍵，最後都呼叫同一個純函式產生 Op（延續 v7 §5.5），測試只測純函式。
- **預覽用既有管線**：`makePreview(op, cap, committed=false)` 已支援不 commit 只預覽（拖拉用的），卡片與把手都走它，不新增預覽機制。
- **不做**：自由曲面雕刻、三維圓角（沿兩個軸同時圓）、任意多邊形工具、撤銷以外的歷史分支、快捷鍵自訂。
- **不做**：為了「放大比較省效能」加任何東西；聚焦模式只是自動把範圍設成該結構。

## 4. 設計

### 4.1 3D 視角：旋轉中心永遠在模型上（M10.1）

`views.tsx` 的 OrbitControls 只留旋轉與平移，滾輪自己接（`controls.enableZoom = false`、`zoomToCursor` 拿掉）：

1. **滾輪＝朝游標下的實際表面縮放**。wheel 時用既有的 `hit(clientX, clientY)`（BVH）打一下：
   - 有打到點 H：相機沿 `H − pos` 移動 `(1 − 1/s)` 的比例（s＝縮放倍率，和現在一樣 `exp(−deltaY×0.0015)`），然後 **target 放在視線方向上、和 H 同深度的點**：`target = pos' + viewDir × ((H − pos')·viewDir)`。視線方向不變所以畫面不跳，但旋轉中心落在你看的那個面上。
   - 沒打到：朝現在的 target 縮放（傳統行為），target 不動。這樣朝空白滾永遠不會把中心帶走。
   - 距離下限改成和**選取**有關：有選取時 `minDistance = 0.3 × 選取外框對角線`，沒選取時維持 `size × 0.08`；上限 `size × 8` 不變。
2. **旋轉開始就把中心放到游標下**。左鍵（無修飾鍵）pointerdown 時 raycast，命中就用同一條公式把 target 移到該深度（不改視線方向）。現在只有雙擊做這件事，改成每次旋轉都做；雙擊模型改成「對準那個點」（`moveTo`，有動畫）。
3. **自動回正**。每次 wheel／旋轉結束後檢查：target 在模型包圍盒放大 25% 之外、或相機距離 > `fullRadius × 3`、或包圍盒 8 個角投影全部在畫面外 → 300 ms 動畫把 target 拉回包圍盒中心（相機位置不動，只轉頭）。雙擊空白＝全貌維持。
4. **極點**：`minPolarAngle = 0.02`、`maxPolarAngle = π − 0.02`；上視預設從 `(0, 1, 0.0005)` 改成 `(0, 1, 0.035)`（約 2°），在上視也能繼續拖。
5. 開發模式把 `controls` 掛在 `window.__controls` 給 e2e 讀。

### 4.2 2D 手勢：節點預設保直角（M10.2）

`snap.ts` 的 `dragDisp`／`dragDispFloat` 節點分支改成三種，依修飾鍵與局部形狀決定：

| 情況 | 行為 | 鍵 |
| --- | --- | --- |
| 節點兩側（到相鄰節點為止的段）都是軸向直邊 | **矩形角**：和它共邊的水平邊整條沿 v 平移 `dv`、垂直邊整條沿 u 平移 `du`；對角不動（像拖矩形的角） | 預設 |
| 任一側不是直邊（弧、斜邊） | **單點**：只動這一點，相鄰兩段線性內插（放開是兩條直線） | 預設（＝現在的 Shift） |
| 任何節點 | **自由衰減**：現在的 cos 衰減 | Alt＋拖 |
| 任何節點 | 單點 | Shift＋拖（不變） |

- `edgeAmount`／邊的拖法不變。
- 熱區：`NODE_PX` 8 → 6；節點與邊同時在範圍內時**比距離**（兩者都除以各自半徑再比），不再節點永遠優先；游標在節點上顯示 `nwse-resize`／`nesw-resize`（依角的象限），在邊上顯示 `ns-resize`／`ew-resize`，區域顯示 `move`。
- 拖拉中的 ghost 加**自交偵測**（`editRing` 後 O(n²) 線段相交，n ≤ 200）：自交時輪廓轉紅、提示「輪廓自交，放開會出現缺口」；仍允許放開（使用者可能故意）。
- 右欄「選到的節點」卡片加一個「拖法」三選（矩形角／單點／自由衰減），和拖拉同一條路。
- `relative.ts` 的 `RelGesture` 多一欄 `drag: 'corner' | 'single' | 'falloff'`，舊 Op 沒這欄＝`falloff`（重播不變）。

### 4.3 改過的地方：不染色，差異模式才標（M10.3）

- **改後（現在）模式**不再帶 `DIFF_BIT`：`chunks`／`preview` 呼叫一律 `diff: false`；切面不描紅邊。`showDiff` 狀態與設定裡的「改過的地方標紅」刪除。
- **差異模式**（D）改成：沒改的半透明灰（不變）、改過的實色＋**藍邊 `#1677ff`**（`changedEdges` 顏色換掉）、被拿掉的紅（不變，紅在這裡是「原本的影子」）；切面同樣藍邊、被拿掉的紅。
- 分段按鈕改名：**改後／改前／差異**（B：改後 ⇄ 改前，D：改後 ⇄ 差異）；「原始」這個字只留給「原始模型」這個 split。
- 左欄的「已改」點、右欄「已改動」、改動頁籤的數字都留著——它們不靠顏色。
- `DIFF_BIT` 與 `colorFn` 的混紅分支保留給差異模式用（差異模式的實色＝原色，不混紅）。

### 4.4 數值操作：每一張卡片都是「預覽 → 套用」（M10.4）

新元件 `OpCard.tsx`，右欄的「長／縮」「方頭」「圓頭」「移動」「材質」各一張；2D 浮動列與 3D 右鍵開的是**同一張卡片**的 Popover 版本。

每張卡片固定三段：

1. **參數**：方向用**六面小方塊**（`FacePicker`：一個等角小立方體，六面各一顆按鈕，滑過時 3D 的選取外框對應那一面亮橘色＋箭頭，`View3D` 新增 `handle.highlightFace(dir | null)`；2D 時主切面對應那條邊亮起）；格數＝滑桿＋輸入框＋nm。
2. **一句話**：`opWords.ts` 的 `describeOp(ed, op)`：「Poly-Si 2 頂面 y 40 → 37（長高 3 格 = 1.5 nm）· HfO₂ 襯層跟著 · 整根」；補平寫「每一排補到 y = 37」；移動寫「往右 2、往上 1」；材質寫「Si fin 1 → TiN，12,480 格」。資料都已有（`levelTarget`、`bboxDims`、`scopeWords`、`selCount`）。
3. **套用**：參數一變（debounce 150 ms）就 `makePreview(op, LIVE_PREVIEW_CAP, false)` 畫淡綠／淡紅；按「套用」（Enter）才 `commit`；卡片收合、Esc、點別處 → `endLive()`。超過預覽上限時卡片顯示「範圍太大，不先畫，套用後 Worker 幾秒內顯示」。

- 範圍控制 `ScopeControl` 收進卡片下方一行（「套用到：整根 ▾」），位置列只顯示不再有第二份控制。
- 「選到的節點／邊」保留為一張卡片（數值＋拖法），同樣預覽→套用。
- 「長高／縮短」在 3D 標題列的兩顆按鈕刪除；想一格一格按，卡片的格數旁有 ±。

### 4.5 3D 聚焦編輯：把手取代「在面上拖」（M10.5）

**狀態**：`editor.ts` 新增 `focus: null | { keys: string[]; view: '3d' | '2d' }`。

**進入／離開**（決策 D1）：
- `E` 鍵、雙擊已選結構、右鍵「編輯 {結構}」三種都進；進入時相機 `fit`、`scope` 設成整根、其他結構半透明（`View3D` 新 prop `dimOthers`：非選取 chunk 的材質 opacity 0.25、`depthWrite=false`，選取實色；既有「材質半透明」顯示選項維持獨立）。
- 聚焦中再按 `E`：3D 把手 ⇄ 2D 剖面（2D 剖面＝現在的 `SliceEditor` 主畫面，整套不變）。
- `Esc` 離開：選取與範圍留著。現在的「2D 編輯 (E)」按鈕變成編輯工具列的一個頁籤（§4.7）。

**3D 把手**（新檔 `handles3d.ts`，純函式產生把手幾何與拖拉 → Op；`views.tsx` 只畫與接事件）：

| 把手 | 畫在哪 | 拖它 | 產生 |
| --- | --- | --- | --- |
| **面把手** ×6 | 選取外框每一面中央一個箭頭（螢幕固定 18 px，背對相機的面不畫） | 沿法線拖，`screenVectors` 算 px/voxel，取整得 n；拖的時候 `onPreview(push op)`，游標旁「+3 vx（1.5 nm）」 | `push {dir, n}`，和卡片同一個 |
| **角把手** ×4 | 剖面（軸＝結構最長軸的法線，和 2D 自動選的一樣）四個角，畫在範圍中點那一片的稜線上，小菱形 | 沿角平分線往內拖＝半徑 r；拖的時候預覽；點一下開圓頭卡片 | `round`（§4.6） |
| **筆刷**（決策 D2） | 工具列切到「筆刷」才有；行為同現在（推拉／補平、半徑、圓方） | 同現在 | `push`／`level` 局部 |

- 左鍵按在把手上才是編輯（capture 階段判斷，和現在筆刷同一招），其他地方一律轉視角；Alt＋拖、中鍵的轉視角說明刪掉（還能用，但不用教）。
- 「3D 雕刻：開／關」Tag、設定裡「在 3D 上雕刻」、筆刷裡「關閉（只轉視角）」三個開關全部刪除：不在聚焦模式就沒有編輯，聚焦模式裡預設是把手。
- 把手的 hover 提示：面把手「拖＝{方向}長／縮」、角把手「拖＝圓角半徑，點一下調參數」。
- 右鍵（聚焦中，點在結構上）：「對準這裡」「{方向}長／縮…」（開卡片，方向＝點到的面的法線）「方頭（往{方向}）」「圓頭…」「換材質 ▸」「在這個面上看 2D 剖面」（軸＝法線、片＝點到的體素）。

### 4.6 圓頭 `round` Op：參數化、2D／3D 同一個面板（M10.6）

```ts
interface RoundOp {
  kind: 'round';
  keys: string[];
  scope: Scope;            // axis = 剖面法線（結構最長軸）
  at: number;              // 參考片（顯示用）
  corners: { id: 'ul' | 'ur' | 'll' | 'lr'; concave?: boolean }[];  // 哪些角；concave = 內圓角（往外填）
  r: number;               // 半徑（vx）
  ru?: number; rv?: number; // 不對稱（橢圓角）；rv 在介面上也叫「肩高」；沒給＝r
  n: number;               // 方圓度：1 斜切、2 正圓、越大越方（超橢圓指數）
  mode: 'cut' | 'fill' | 'match'; // 只削／只填／對齊到目標形狀（預設 match）
  follow: boolean; backfill: Backfill; text: string;
}
```

**每一片怎麼算**（`slice/round.ts`，純函式）：
1. 描這一片已選結構的外環 → `ringsBox` 得外框 B（不用描出來的角點，頭型已經是圓的也一樣能定義目標）。
2. 目標多邊形＝B 的矩形，每個被勾的角換成超橢圓弧：以角為基準、圓心在往內 `(ru, rv)` 處，`t ∈ [0, π/2]` 取 `x = ru·cos^(2/n) t`、`y = rv·sin^(2/n) t`，每格長度至少 2 個點；凹角（`concave`）則是在角**外側**的象限補四分之一弧（圓心在往外 `(ru, rv)` 處），只填空氣（kernel 決定）。
3. `rasterize` → 和這一片現在的格子 `deltaOf`：`mode = 'cut'` 丟掉 add、`'fill'` 丟掉 remove、`'match'` 都留。
4. 之後和 profile 一樣：先拿再加、由近到遠、要 4 鄰接、kernel 規則、襯層跟著。

**套用到範圍**：`RelGesture` 多一種 `kind: 'round'`（記 corners、r、ru、rv、n、mode），每一片用自己的外框重算，所以永遠對得到（沒有 fallback）；參考片 `refExact`。Worker 的 `applyProfileMask` 多認一種 gesture；`profileBox` 的外框＝外框 B 往外擴 `max(ru, rv) + 襯層`。

**面板（`RoundCard`，就是 `OpCard` 的一種）**：
- 一張剖面小圖（結構的外框示意），四個角各一顆可點的圓點：點一下切「不圓 → 外圓角 → 內圓角」；預設上面兩個外圓角。
- 半徑 r（滑桿＋輸入，vx／nm 切換），上限＝min(半寬, 半高)，超過就夾住並提示。
- 「不對稱」開關 → 出現 ru（寬）／rv（高，標「肩高」）。
- 方圓度 n：滑桿 1～8，刻度標「斜切 1 · 圓 2 · 方 8」，小圖即時畫出該形狀。
- 模式：對齊形狀（預設）／只削／只填。
- 一句話：「Poly-Si 2 上面兩個角圓角 r = 6（3.0 nm）、n = 2 · 削 1,240 格、填 0 格 · 整根」。
- 「方頭」按鈕＝`level`（現在的補平）放在同一張卡片的右上角：同一個地方決定頭型。
- 限制提示：r < 3 格時寫「體素太粗，看起來會像斜切」。

**從哪裡開**：右欄卡片、2D 浮動列「圓頭…」、2D 角節點右鍵「圓角…」、3D 角把手點一下、3D 右鍵「圓頭…」。全部是同一個元件、同一個 Op。

## 8. 風險與對策

| 風險 | 對策 |
| --- | --- |
| 自接 wheel 和 OrbitControls 的阻尼／`update()` 互相干擾 | wheel 只改 `camera.position` 與 `target`，之後呼叫 `controls.update()`；e2e 連滾 20 格檢查沒有抖動 |
| 矩形角拖法在 L 形、T 形剖面上「共邊的整條邊」定義不直覺 | 「整條邊」＝到相鄰節點為止的那一段（`smoothEdgeGroup`），不是整個外框；卡片裡可切回單點 |
| 圓頭在頭型已經是圓的結構上，`match` 模式會同時削與填，格數看起來很多 | 一句話分開列「削 n、填 m」；預覽先畫；預設 `match` 但卡片第一行就能切「只削」 |
| 面把手和選取外框、剖面貼圖、筆刷圈在畫面上打架 | 把手固定螢幕大小、`depthTest=false`、renderOrder 最高；筆刷模式下不畫把手 |
| 改名後舊使用者找不到 | 第一次開新版本在左下角提示「長高／縮短改叫長／縮、補平改叫方頭」一次；`?` 裡有對照表 |
| `E` 從「進 2D」變成「進聚焦（3D）」 | 聚焦內再按 E 切到 2D，等於多按一次；README 與說明寫清楚 |
