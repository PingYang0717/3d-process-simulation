## 0. 一句話

打開檔案 → **點一個結構 → 按「外推／內縮」或拖箭頭 → 匯出**。整個畫面只有一頁、沒有模式、沒有 split，不用看說明就會用。

## 2. 「一眼就懂」的七條規則

1. **沒有模式**。選到結構，箭頭就出現、面板就可以按。不存在「瀏覽／3D 把手／2D 剖面／筆刷」這種要先切換的狀態。
2. **每件事都有看得見的按鈕**。不靠右鍵、雙擊、快捷鍵才做得到的功能一個都沒有（快捷鍵只留 Ctrl+Z／Ctrl+Y／Esc，而且旁邊都有按鈕）。
3. **照順序由左到右**。左欄 ① 選結構 → ② 要做什麼；中間看 3D；右邊看 2D。畫面上的 ①② 就是操作順序。
4. **只用白話**。畫面上只出現：外推、內縮、平移、換材質、上下左右前後、格、nm、相鄰材質、跟著移動、留在原地、復原。不出現 x／y／z、voxel、scope、split、法線、襯層、policy、backfill。
5. **按下去馬上生效，不滿意按復原**。沒有「預覽中、還沒套用」這個中間狀態（§8 D2）。拖箭頭的時候即時看到結果，放開就是完成。
6. **做完用一句話說發生了什麼**。底部狀態列：「Poly-Si 2 上面外推 2 格（1.0 nm）· HfO₂、TiN 跟著移動 · 復原」。
7. **做不到要說為什麼、而且事先就看得出來**。例如已經貼到模型邊界：那個方向的按鈕反灰，滑過去寫「已經到模型邊界」。

## 4. 三個動作

所有動作都作用在**整個結構**（不再有「套用到哪一段」）。一次只能選一個結構（§8 D4）。

### 4.1 推拉一面（外推／內縮）

1. 選面：按面板上的「上／下／左／右／前／後」，或直接點 3D 上的箭頭。選到的那一面在 3D 上整面亮橘色。
2. 動作：按 **［外推］** 或 **［內縮］**，一次動「每次 n 格」（預設 1，旁邊寫等於幾 nm）；或在 3D 上**順著箭頭拖＝外推、反方向拖＝內縮**，游標旁即時顯示「外推 3 格（1.5 nm）」，放開完成。
3. 只動那個方向最外層的表面：形狀不變、內部的洞不會被填（現有引擎的 `push`）。

### 4.2 整塊平移

- 面板換成六顆方向鍵（上下左右前後），按一下搬「每次 n 格」；或在 3D 上拖箭頭，整個結構跟著走。
- 結構的形狀與大小完全不變，只有位置變（現有引擎的 `translate`）。

### 4.3 相鄰材質：跟著移動｜留在原地

兩個動作共用同一個開關，永遠看得到，旁邊一張小圖直接畫出差別。

| | 跟著移動 | 留在原地 |
|---|---|---|
| 外推 | 貼著這一面的鄰居整層往外讓，**厚度不變** | 鄰居不動，被蓋掉 n 格，**變薄** |
| 內縮 | 鄰居整層跟著往內，**厚度不變** | 鄰居不動位置，但把空出來的地方補滿，**變厚** |
| 平移 | 包在外面的鄰居整圈一起搬 | 只有這個結構搬：前面的鄰居被蓋掉、後面空出來的由鄰居補滿 |

**「相鄰材質」指的是誰**（這是整份規格最需要你確認的地方，§8 D1）：建議沿用現有引擎的判定——**貼著那一面、厚度 4 格以內的薄層**會跟著（可以一層疊一層，例如 HfO₂＋TiN）；更厚的材質（基板、填充層）不搬，只是讓出位置或補滿。為了不讓使用者去記這條規則，面板在開關下面**直接寫出名字**：「會跟著的：HfO₂、TiN」，滑過去 3D 上那幾層會亮起來；沒有薄層貼著時寫「這一面沒有會跟著的鄰居」，開關反灰。

空出來的地方永遠由鄰居補滿，不會留下空氣（現有的 `backfill: 'outer'`）；外面本來就是空氣才是空氣。

## 5. 換材質

面板列出所有材質（色塊＋名字，目前的打勾），**點一下就換**，3D 立刻變色（現有的即時變色）。清單最後固定有「空氣」與「空洞（VOID）」。換的是整個選到的結構。

## 6. 2D 視窗（只看）

- 三張切面（正面／上面／側面）固定在右欄，畫法、顏色和現在相同。
- 能做的：拖滑桿或滾輪**換片**；滑過顯示材質名稱；**點一下選結構**（等同點 3D）；選到的結構描藍邊；3D 上拖箭頭時，切面即時顯示會變成什麼。
- 不能做的：任何會改到體素的操作。沒有節點、沒有右鍵選單、沒有「進入 2D 剖面」。
- 切面位置預設跟著選到的結構（切在它中間），所以選了東西就一定看得到它。

## 7. 沒有 split 之後

- 狀態只有兩個：**原始**（唯讀）與**目前**（原始＋你做過的每一步）。
- 復原／重做照舊（50 步或 256 MB）。「看原始」用來對照；「全部還原」回到剛載入的樣子。
- 匯出：一顆按鈕，輸出**一個** `.vti`，格式和輸入相同（沿用現有的同格式匯出；比例陣列＋FieldData 的檔案未改到的部分 bit-identical）。不再有 zip、manifest、`.npy` 選項。
- 差異模式（半透明＋深藍邊）先拿掉，由「看原始」取代（§8 D3）。

## 8. 需要你決定的四件事

| | 問題 | 我的建議 | 另一個選項 |
|---|---|---|---|
| **D1** | 「相鄰材質」怎麼判定誰會跟著？ | **4 格以內的薄層自動跟，面板寫出名字**。現有引擎已經是這樣，不用改核心規則。缺點：厚的蓋層（例如 Poly 上面很厚的 SiN cap）不會跟著，要分兩步做。 | 面板把貼著的鄰居一層一層列出來，**讓你自己勾哪幾層跟**（厚的也可以）。最透明、什麼情況都做得到，但要改核心規則（`kernel.ts` 的薄層判定改成「指定材質」），多一輪逐體素測試。 |
| **D2** | 按下去馬上生效，還是先預覽再按「套用」？ | **馬上生效＋復原**。少一個狀態、少一顆按鈕。大檔（5,000 萬格）每一步約 0.5～1 秒，期間有進度條、可取消。 | 沿用現在的「先看再套用」：比較保險，但多一個「我到底套用了沒」的狀態。 |
| **D3** | 改了哪些地方要怎麼看？ | 只留「看原始」切換。 | 另外保留現有的差異模式（沒改的半透明、改過的實色）。功能現成，但多一顆按鈕、多一個概念。 |
| **D4** | 一次可以選幾個結構？ | **一次一個**。「相鄰材質」的說明才寫得清楚。 | 保留 Ctrl＋點多選，一起推、一起搬。 |

另外三件我先照最簡單的做，不同意再說：3D「剖面」（沿某軸剖開）先拿掉，看裡面用 2D 切面與結構清單；`.npy` 上傳保留、匯出只有 `.vti`；內建範例只留「簡單範例」與「複雜範例」各一個（不要 ×2／×3）。

## 9. 驗收（開工後怎麼算完成）

找一個沒看過這個工具的人，不給任何說明，用複雜範例在 **3 分鐘內**完成下面四件事就算過；任何一件需要問人就不算：

1. 把 Poly-Si 2 加高 2 格，外面的薄層跟著。
2. 把 Si fin 1 往左搬 3 格，鄰居留在原地。
3. 把一個結構換成另一種材質。
4. 復原最後一步，然後匯出。

另外自動檢查：整頁沒有捲軸（1280×720 起）；`npm run typecheck`、`npm test`、`npm run build` 全過；推拉、平移、換材質的結果和完整版同一個 Op 逐體素相同（沿用現有測試）。

## 10. 開工後的做法（供參考，還沒做）

核心規則和 Worker 都不用重寫——簡化版用到的三種 Op（`push`、`translate`、`material`）和即時預覽、進度／取消、同格式匯出，完整版都已經有而且有逐體素測試。工作幾乎都在畫面層：

| 步驟 | 內容 |
|---|---|
| M1 新版面 | 新的單頁版面（左欄 ①②、3D、右欄三張唯讀切面、狀態列）；選到就出現箭頭（拿掉聚焦編輯的切換）；新的動作面板取代 `OpCard`／`Inspector`／`EditToolbar`。 |
| M2 相鄰材質 | 開關接到 `follow`、`policy`、`backfill`；「會跟著的：…」由選到的那一面往外掃一次算出來。D1 選另一個選項的話，這一步要加上核心規則的修改與測試。 |
| M3 拿掉 split | 內部固定只有一份「目前」；移除實驗頁、Split 選單、比較、表格、zip 匯出。 |
| M4 刪程式 | 刪掉已經到不了的程式與測試：2D 編輯（`src/slice/` 約 2,400 行）、實驗頁與 split 相關畫面、方頭／圓頭／筆刷等卡片（畫面層約 7,700 行）、`factors.ts`、`profile.ts`、`splits/lifecycle.ts`（約 1,200 行）。現有非測試程式約 26,600 行，預計剩一半左右。 |
| M5 驗收 | §9 的四件事跑 Playwright 腳本＋截圖。 |

風險：`editor.ts`（1,877 行）與 `views.tsx`（2,384 行）把聚焦編輯、範圍、split、2D 編輯綁得很緊，M3／M4 要小心一段一段拆，每拆一段跑一次測試。
